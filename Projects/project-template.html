XSS & Web App Hardening Lab

Problem: Demo app reflected user input without encoding, enabling XSS.

Environment: OWASP Juice Shop (v14), Burp Suite CE, OWASP ZAP, Chrome.

Approach

  1. Mapped attack surface; identified sinks via Burp.
  2. Verified payloads (<script>alert(1)</script>, DOM-based probes).
  3. Mitigations: output encoding, input validation, CSP (script-src 'self' 'nonce-123').

Evidence

  • Before/after screenshots (PII redacted).
  • Blocked payload classes; CSP violation reports.

Impact

Neutralized reflected & DOM XSS classes; added defense-in-depth with CSP and encoding.
